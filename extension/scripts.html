🛡️ Thurea – Userscripts

Userscripts are switched off in Chromium.
  1. Click the button below to open Thurea's details page.
  2. Turn on Allow User Scripts.
  3. Come back here. This message disappears once it's on.

Tip: opening any .user.js link (for example on Greasy Fork) brings you straight to Thurea's install page.
